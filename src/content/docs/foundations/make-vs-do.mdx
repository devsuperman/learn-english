## Explanation

Many languages use **one verb** where English uses two: **make** and **do**.

- **Do** is for tasks, activities and work: *do a task, do an interview, do a code review, do your best*.
- **Make** is for creating or producing something: *make a decision, make a mistake, make a change, make a plan*.

When you are not sure, ask yourself: *Am I creating something new?* If yes, use **make**. If it is an activity, use **do**.

## Key phrases

| Do | Make |
| --- | --- |
| do an interview | make a decision |
| do a code review | make a mistake |
| do some research | make a change / a commit |
| do a task / a ticket | make progress |
| do a deployment | make a suggestion |

## Common mistakes

| ❌ Don't say | ✅ Say | Why |
| --- | --- | --- |
| I **made** an interview yesterday. | I **had / did** an interview yesterday. | An interview is an activity. |
| I have experience **in** Python **since** 5 years. | I have **5 years of** experience with Python. | Use *X years of experience* with a duration. |
| Can you **explain me** the bug? | Can you **explain** the bug **to me**? | *Explain* takes *to* before the person. |
| I **actually** work at a bank. | I **currently** work at a bank. | *Actually* means "in fact", not "now". |
| **Is** possible to deploy today? | **Is it** possible to deploy today? | English sentences need a subject. |
