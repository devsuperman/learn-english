## Explanation

In tech, you compare things all the time: languages, tools, architectures, solutions.

| Adjective | Comparative | Superlative |
| --- | --- | --- |
| Short (1 syllable): *fast, cheap* | fast**er**, cheap**er** | the fast**est**, the cheap**est** |
| Ending in -y: *easy, heavy* | eas**ier**, heav**ier** | the eas**iest**, the heav**iest** |
| Long (2+ syllables): *expensive, scalable* | **more** expensive | **the most** expensive |
| Irregular: *good, bad* | **better**, **worse** | **the best**, **the worst** |

Use **than** after a comparative: *Go is faster **than** Python.*

### Useful structures for trade-offs

- *X is **much / a lot** faster than Y.* (big difference)
- *X is **slightly / a bit** more expensive than Y.* (small difference)
- *X is **not as** flexible **as** Y.*
- *X is **as** reliable **as** Y.* (equal)
- *The **more** traffic we have, the **more** we pay.*

## Key phrases

- *PostgreSQL is more reliable for this use case than MongoDB.*
- *The new version is much faster than the old one.*
- *This is the simplest solution, but not the most scalable.*
- *Option A is cheaper, but it's not as flexible as option B.*

## Common mistakes

| ❌ Don't say | ✅ Say | Why |
| --- | --- | --- |
| more **fast** | **faster** | Short adjectives take *-er*. |
| more **better** | **better** | Don't double the comparative. |
| faster **that** Python | faster **than** Python | Comparatives use *than*. |
| the **more** important feature | the **most** important feature | Superlative: *the most*. |
| **expensiver** | **more expensive** | Long adjectives use *more*. |
