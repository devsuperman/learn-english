## Explanation

Use **does** to make questions in the **present simple** when the subject is:

- **he, she, it**
- a **singular noun**: *the app, the API, your manager, this endpoint*
- a **team or company**: *your team, the company*. In American English, these words are singular.
- **everyone, anyone, someone**: these words are singular too.

The *-s* of the verb **moves to *does***. The main verb loses its *-s*:

| Statement | Question |
| --- | --- |
| She **works** remotely. | **Does** she **work** remotely? |
| The API **returns** JSON. | **Does** the API **return** JSON? |
| The app **has** dark mode. | **Does** the app **have** dark mode? |
| The job **runs** at night. | **Does** the job **run** at night? |

*Does* is very common when you talk about **how systems work**:

- ***How does** the cache **work**?*
- ***What does** this error **mean**?*

**Short answers:** *Yes, it does.* / *No, she doesn't.*

:::caution[When you don't need does]
With **be** (*is*) and with **modals** (*can, will, should*), don't use *does*: *"**Is** the server running?"*, *"**Can** it handle 1,000 requests per second?"*
:::

## Key phrases

- *Does that make sense?*
- *Does anyone have any questions?*
- *How does the cache work?*
- *What does "LGTM" mean?*
- *Does the API support pagination?*
- *Does your team use Scrum?*
- *Which service does the login page call?*

## Common mistakes

| ❌ Don't say | ✅ Say | Why |
| --- | --- | --- |
| Does he **works** remotely? | Does he **work** remotely? | After *does*, the verb has no *-s*. |
| Does the app **has** dark mode? | Does the app **have** dark mode? | After *does*, *has* becomes *have*. |
| What **means** "SLA"? | What **does** "SLA" **mean**? | Question word + *does* + subject + base verb. |
| **Do** the API return JSON? | **Does** the API return JSON? | *The API* = *it*, so use *does*. |
| How **works** the login? | How **does** the login **work**? | Use *does*, then put the verb after the subject. |
| **Does** she **is** your manager? | **Is** she your manager? | With *be*, don't use *does*. |
