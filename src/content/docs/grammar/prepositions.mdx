## Explanation

Prepositions are hard because they don't translate word for word. Learn them **in combinations**, not alone.

### Time

| Preposition | Use | Example |
| --- | --- | --- |
| **for** | A duration | *for three years, for two weeks* |
| **since** | A starting point | *since 2020, since Monday* |
| **in** | Months, years, longer periods | *in May, in 2023, in Q3* |
| **on** | Days and dates | *on Friday, on March 3rd* |
| **at** | Exact times | *at 10 a.m., at the end of the sprint* |
| **by** | A deadline (no later than) | *by Friday, by end of day* |
| **until** | Up to a moment, continuously | *I'm off until Monday.* |

### Work and tech

| Combination | Example |
| --- | --- |
| work **at** / **for** a company | *I work **at** Spotify.* / *I work **for** a bank.* |
| work **on** a project or feature | *I'm working **on** the checkout.* |
| work **with** a technology or people | *I work **with** Go and Kafka.* |
| experience **with** / **in** | *experience **with** AWS, experience **in** backend development* |
| **in** a meeting, **on** a call | *I'm **in** a meeting. I'm **on** a call.* |
| **on** Slack, **on** GitHub, **on** the website | *I'll message you **on** Slack.* |
| send **to**, explain **to**, talk **to** | *Can you explain it **to** me?* |
| depend **on**, focus **on** | *It depends **on** the traffic.* |

## Common mistakes

| ❌ Don't say | ✅ Say |
| --- | --- |
| I work here **since** two years. | I've worked here **for** two years. |
| I work **in** Google. | I work **at** Google. |
| See you **in** Monday. | See you **on** Monday. |
| It depends **of** the client. | It depends **on** the client. |
| I'm **in** a call. | I'm **on** a call. |
| I need it **until** Friday. *(deadline)* | I need it **by** Friday. |
