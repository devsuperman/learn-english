## Explanation

Use **did** to make questions in the **past simple**: about finished actions, like yesterday's work, the last sprint or an incident. *Did* is the same for **every subject**: *I, you, he, she, it, we, they*.

The past tense **moves to *did***. The main verb goes back to the **base form**. This is true for regular verbs and for **irregular verbs**:

| Statement | Question |
| --- | --- |
| You **fixed** the bug. | **Did** you **fix** the bug? |
| The deploy **went** well. | **Did** the deploy **go** well? |
| She **wrote** the tests. | **Did** she **write** the tests? |
| It **broke** production. | **Did** it **break** production? |
| They **found** the cause. | **Did** they **find** the cause? |

**Clue words** for *did*: *yesterday, last night, last sprint, this morning, two hours ago, in 2023*.

**Short answers:** *Yes, I did.* / *No, it didn't.*

:::caution[When you don't need did]
With **was / were**, don't use *did*: *"**Was** the build green?"*, *"**Were** you in the meeting?"*
:::

## Key phrases

- *Did you have a chance to look at my PR?*
- *Did the deploy go well?*
- *What did you work on yesterday?*
- *When did the incident start?*
- *Did anyone change the config?*
- *How did you find the bug?*
- *Why did the job fail?*

## Common mistakes

| ❌ Don't say | ✅ Say | Why |
| --- | --- | --- |
| Did you **fixed** the bug? | Did you **fix** the bug? | After *did*, use the base verb. |
| Did it **broke** prod? | Did it **break** prod? | Irregular verbs too: base form after *did*. |
| Did you **went** to the meetup? | Did you **go** to the meetup? | *went* → *go* after *did*. |
| You **finished** the ticket? | **Did** you **finish** the ticket? | A past question needs *did*. |
| What you **did** yesterday? | What **did** you **do** yesterday? | Question word + *did* + subject + base verb. |
| **Did** the build **was** green? | **Was** the build green? | With *was / were*, don't use *did*. |
| **Does** he call you yesterday? | **Did** he call you yesterday? | *Yesterday* is past, so use *did*. |
