## Explanation

In the **active** voice, the subject **does** the action. In the **passive** voice, the subject **receives** the action.

- Active: ***Maria** fixed the bug.* (focus on who did it)
- Passive: ***The bug** was fixed.* (focus on what happened)

**Form:** **be** (in the right tense) + **past participle**.

| Tense | Passive | Example |
| --- | --- | --- |
| Present simple | is / are + participle | *Logs **are stored** in S3.* |
| Present continuous | is / are **being** + participle | *Your PR **is being reviewed**.* |
| Past simple | was / were + participle | *The service **was restarted** at 3 a.m.* |
| Present perfect | has / have **been** + participle | *The issue **has been fixed**.* |
| Future | will **be** + participle | *The feature **will be released** on Monday.* |
| Modal | can / should / must **be** + participle | *This endpoint **should be deprecated**.* |

If you want to say who did the action, use **by**: *The library **is maintained by** Google.*

### When to use the passive

- **Documentation:** *Requests **are authenticated** with a JWT.*
- **Incident reports and release notes:** *The outage **was caused** by an expired certificate.*
- **When the person is unknown or not important:** *The API key **was leaked** in a public repo.*
- **Blameless postmortems:** focus on the system, not on people.

### When NOT to use it

In **interviews**, use the **active** voice with **I**. Interviewers want to know what *you* did.

- ❌ *The database **was migrated** to PostgreSQL.* (who did it?)
- ✅ ***I migrated** the database to PostgreSQL.*

## Key phrases

- *The bug **was introduced** in version 2.3.*
- *The fix **has been deployed** to production.*
- *All data **is encrypted** at rest.*
- *This method **should not be called** directly.*
- *The meeting **has been moved** to Thursday.*
- *I **was asked** to lead the migration.* (passive + your role: useful in interviews)

## Common mistakes

| ❌ Don't say | ✅ Say | Why |
| --- | --- | --- |
| The bug **was fix**. | The bug was **fixed**. | Use the past participle. |
| The error **was happened** yesterday. | The error **happened** yesterday. | *Happen* has no object, so it can't be passive. Same for *occur*, *arrive*, *appear*. |
| The tests **are run** now. *(in progress)* | The tests **are being run** now. | In progress = *being* + participle. |
| The PR **has merged**. | The PR **has been merged**. | Passive present perfect needs *been*. |
| The project **was led by me**. *(interview)* | **I led** the project. | Use the active voice to show ownership. |
