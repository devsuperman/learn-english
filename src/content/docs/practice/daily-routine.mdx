## Explanation

The routine has three blocks of 5 minutes. Do it every working day. Use content from **your own field**, so you learn the vocabulary you'll actually need.

| Block | What to do | Example |
| --- | --- | --- |
| 🎧 Listen (5 min) | Watch part of a tech talk or podcast with English subtitles. | A conference talk about your stack. |
| 🗣️ Shadow (5 min) | Pause and repeat sentences out loud, copying the rhythm. | Repeat 5–10 sentences from the talk. |
| ✍️ Write (5 min) | Write a short standup update about your day. | *Yesterday I… Today I'll… I'm blocked by…* |

## Key phrases for your daily update

- *Yesterday I **worked on** the login page.*
- *Today I'm **going to** fix the flaky tests.*
- *I'm **blocked by** a missing API key.*
- *I **finished** the migration and **opened** a PR.*

## Common mistakes

| ❌ Don't say | ✅ Say |
| --- | --- |
| Yesterday I **work** on the bug. | Yesterday I **worked** on the bug. |
| Today I **will to** fix it. | Today I **will** fix it. / Today I'm **going to** fix it. |
| I'm blocked **for** the API. | I'm blocked **by** the API. |
