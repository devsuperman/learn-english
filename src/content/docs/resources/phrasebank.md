## Buying time to think
- *That's a good question. Let me think for a second.*
- *Could you repeat the question, please?*
- *Just to make sure I understand: you're asking about …?*

## When you don't understand
- *Sorry, could you say that again a bit more slowly?*
- *What do you mean by …?*
- *Could you give me an example?*

## When you don't know the answer
- *I haven't worked with that directly, but here's how I'd approach it …*
- *I'm not sure, but my guess would be …*

## Explaining technical decisions
- *We chose X over Y because …*
- *The main trade-off was …*
- *In hindsight, I would …*

## Agreeing and disagreeing politely
- *That makes sense.* / *Good point.*
- *I see your point, but I'm a bit worried about …*
- *Have we considered …?*
- *What if we tried …?*

## Code review comments
- *nit: could we rename this to …?* (nit = small, optional suggestion)
- *Could you add a test for this case?*
- *Looks good to me!* (LGTM)
- *I'm not sure I follow this part. Could you explain it?*
