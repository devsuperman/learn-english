# CLAUDE.md

Guidance for working in this repository.

## Project

**English for Tech** is a free crash course that helps people learn, practice, do job interviews, and work in English in the tech industry. It's a static site built with **Astro + Starlight** and deployed to **GitHub Pages** at https://devsuperman.github.io/learn-english/.

- **Audience:** everyone (any native language) with basic English (A2–B1), working in or aiming for tech jobs.
- **Roadmap and decisions:** `PLAN.md`. Keep its checkboxes up to date when you add or finish lessons.

## Commands

```bash
npm install
npm run dev       # http://localhost:4321/learn-english/
npm run build     # static output in dist/
npm run preview   # serve dist/ on port 4321
npm run verify    # end-to-end check (needs `npm run preview` running + Playwright/Chromium)
```

Before you commit, run `npm run build`, then `npm run preview` and `npm run verify`.

`npm run verify` (`scripts/check-site.cjs`) crawls every page and checks for:

- broken links and JS errors
- quiz or FixIt answers marked wrong (every `Quiz` correct option and every accepted `FixIt` answer must be accepted)
- `Say` buttons that are hidden or speak the wrong text
- horizontal scroll at 390px width

The build prints a harmless warning: `collection "i18n" does not exist`. You can ignore it.

## Structure

```
astro.config.mjs              # site/base (/learn-english), sidebar groups, Starlight config
src/content.config.ts         # Starlight docs collection
src/content/docs/
  index.mdx                   # splash homepage (module cards)
  start-here/                 # how the course works
  grammar/                    # 1. Grammar (10 lessons)
  vocabulary/                 # 2. Vocabulary & pronunciation
  practice/                   # 3. Daily practice
  interviews/                 # 4. Job interviews
  work/                       # 5. Working in English
  resources/                  # phrasebank, interview question bank
src/components/
  Quiz.astro                  # multiple choice with feedback
  FixIt.astro                 # "fix the sentence" free-text exercise
  Say.astro                   # listen button (browser speech synthesis, en-US)
src/styles/custom.css         # exercise styles, built on Starlight tokens (light/dark)
templates/lesson.mdx          # copy this to start a new lesson
scripts/check-site.cjs        # end-to-end verification
.github/workflows/deploy.yml  # builds PRs; deploys main to GitHub Pages
```

The sidebar is autogenerated per directory. To add a **module**, add a group in `astro.config.mjs`, a card in `index.mdx`, and a row in `PLAN.md` and `README.md`.

## Writing lessons

1. Copy `templates/lesson.mdx` into the module folder. Use a kebab-case filename, which becomes the URL slug.
2. Set `title`, `description` and `sidebar.order`. `index.md` (the module overview) is `order: 0`.
3. Follow the fixed section order: **Explanation → Key phrases → Common mistakes → Exercises → Today's task**. A lesson takes 15–20 minutes.
4. Add the lesson to the module's `index.md` list. If it replaces a *(coming soon)* entry, turn that entry into a link.
5. Link related lessons with a `:::tip[Grammar for this lesson]` aside. For example, interview lessons link to the grammar lessons they rely on.

### Content style

- Write simple, clear English for A2–B1 learners: short sentences and common words. Explain any idiom you use.
- Use **tech-work examples** (PRs, deploys, standups, incidents), not generic textbook ones.
- Keep the course for **all native languages**. You can mention language groups (for example, "speakers of Portuguese, Spanish, French and Italian"), but don't write lessons for only one language.
- Common-mistakes tables use the columns `❌ Don't say | ✅ Say | Why`, and **bold** the changed words.
- Every lesson ends with a concrete **Today's task**: write, record or say something.
- Use American spelling (*color*, *organize*, *canceled*).

### Components (MDX only)

Import the components with relative paths from the lesson file:

```mdx
import Quiz from '../../../components/Quiz.astro';
import FixIt from '../../../components/FixIt.astro';
import Say from '../../../components/Say.astro';

<Quiz question="…" options={["A", "B", "C"]} answer={1} explanation="…" />
<FixIt sentence="Wrong sentence." answers={["Main answer.", "Other accepted answer."]} explanation="…" />
<Say text="queue" />              {/* label + button */}
<Say text="cache" label="" />     {/* button only, e.g. in a table */}
```

- In a `Quiz`, `answer` is **zero-based**.
- `FixIt` compares answers without case or punctuation, but **contractions are different strings**. List both forms (`I have worked…` and `I've worked…`) and every other natural correct answer. Otherwise learners who write a correct sentence will be marked wrong.
- `Say` uses the browser's voice. For acronyms or names that the voice reads badly, pass a phonetic spelling as `text` (for example, `text="engine X"` for nginx).

### Links

- Inside docs, use **relative links with a trailing slash**, because the site is served under the `/learn-english` base path:
  - from a module `index.md`: `./lesson-slug/`
  - from a lesson to the same module: `../other-lesson/`
  - from a lesson to another module: `../../grammar/conditionals/`
- Don't use absolute `/…` links: they skip the base path and break on GitHub Pages.

## Deployment

`.github/workflows/deploy.yml` runs on every pull request (build only) and on pushes to `main` (build and deploy to GitHub Pages). GitHub Pages must be set to **Source: GitHub Actions** in the repository settings.

## Pinned versions

`astro@7.4.11` and `@astrojs/starlight@0.42.11`. Starlight ≥ 0.39 requires sidebar groups in the form `{ label, items: [{ autogenerate: { directory } }] }`.
